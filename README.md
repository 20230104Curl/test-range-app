# 実力判定テスト範囲確定APP

公開URL: https://20230104curl.github.io/test-range-app/

55校舎の範囲確認・校舎管理アプリです。2026年 第４回 定期テスト模擬の５教科に対応しています。

- `docs/`: GitHub Pagesの画面。公開元は `main` ブランチの `/docs`。
- `apps-script/`: Googleドライブ保存用の処理。実行用のフォルダーIDと認証用秘密値はApps Scriptのプロパティで管理します。
- 閲覧はログイン不要、編集は校舎ごとの数字４桁のパスワードが必要です。
- 校舎・中学校・学年の設定と選択範囲はGoogleドライブの非公開フォルダーに保存します。公開APIは閲覧用の情報を返し、更新には校舎認証を要求します。
- 保存データ、学生ID、認証用秘密値はこのリポジトリに含めません。

公開URLから保存完了表示と、ログインしていない別画面への反映を確認済みです。動作確認に使用した範囲は元に戻しています。
